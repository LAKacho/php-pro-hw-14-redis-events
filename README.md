# ДЗ 14. Приоритетные события в Redis

Система добавляет и очищает события, а по параметрам запроса возвращает подходящее событие с наибольшим приоритетом. У события совпасть должны все условия.

Слой хранения отделён интерфейсом `EventStorage`. Реализация Redis хранит JSON в hash и порядок приоритетов в sorted set; тесты используют заменяемое хранилище в памяти.

## Запуск

```bash
composer install
php tests/run.php
docker compose up -d
REDIS_URL=tcp://127.0.0.1:16379 php bin/demo.php
```

Для другого адреса Redis задайте `REDIS_URL`.
